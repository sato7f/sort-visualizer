# Sort Visualizer

各種ソートアルゴリズムの動きを棒グラフや画像で可視化するWebアプリです。  
単一のHTMLファイルで動作し、サーバー不要でブラウザだけで使えます。

## デモ

https://sato7f.github.io/sort-visualizer/

ローカルで動かす場合は `index.html` をブラウザで開くだけで動作します。

## 使い方

1. `▶` ボタンでソート開始
2. `▶REC` ボタンでソート開始と同時に録画（完了後に動画を保存可能）
3. `↺` ボタンで中断/リセット
4. `⚙` ボタンで設定パネルを開閉

### 設定項目

| 項目 | 説明 |
|------|------|
| アルゴリズム | バブル / 選択 / 挿入 / クイック / マージ / ヒープ |
| 要素数 | 40 / 80 / 120 / 240 / 480 |
| 速度 | スライダーで調整 |
| 音 | ON/OFF切替 |
| 動画 | アップロードすると映像の最初のフレームを画像に、音声を自動設定 |
| 画像 | アップロードすると等間隔に縦分割してソートの要素として表示 |
| 音声 | アップロードすると等間隔に区切り、各要素のアクセス時に対応区間を再生（1〜2秒程度の音声推奨） |

## 動作環境

モダンブラウザ（Chrome, Firefox, Safari, Edge）  
Web Audio API を使用しています。
